What “counterfeit central closure” means

All four radial residuals vanish while at least one lateral residual is nonzero. This is a mathematical distinction between two receivers. For the four-state aperture [0,1,0; 1,1,1; 2,1,2], all radial residuals are 0 but the top and bottom lateral residuals are −2 and +2. It is a synthetic admissible code example, not a claim that a selected automaton produces it. A fully known binary aperture cannot exhibit this distinction: each opposite pair must equal twice its binary center, forcing all nine values to agree. Unknown time slots never count as passing checks.
