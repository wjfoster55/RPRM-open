# Forking and extending

This repository is a self-contained starting point. Fork it, change it,
redistribute it, or use selected modules under their licenses.

When extending a mathematical claim, name the changed carrier, operation,
receiver or assumption. Include a worked example and a hostile case. Keep
written proof, machine-checked proof and finite computation distinct.

For code changes, run the documented checks on the modified source. Preserve
counterexamples. A new test result should report its actual finite scope.

No pull-request review or ongoing maintenance is promised. If no maintainer
responds, the licenses already permit independent continuation.
