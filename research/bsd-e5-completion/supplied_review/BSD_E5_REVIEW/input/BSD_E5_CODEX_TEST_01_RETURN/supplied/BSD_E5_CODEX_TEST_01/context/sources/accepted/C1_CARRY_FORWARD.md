## What can be reused

The prototype represents exact rational-valued laws `f:{0,1}^3 -> Q`, with coordinates `(h,x,y)` and address bits 0, 1 and 2 respectively. Every eight-site table has a unique multilinear coefficient representation. Its hot `C2` summary retains seven coefficients of degree at most two, equivalently the seven values on `B2={0,...,6}`, and omits the three-way coefficient/site 7. Grade is relative to this declared origin and basis.

The summary supports exact pointwise addition and multiplication. Addition is ordinary addition over Q; multiplication uses Boolean reduction, so a monomial product has the union of its coordinate supports. An omitted three-coordinate term cannot contribute a lower-degree term. These operations therefore need only the retained inputs. The precise algebraic description is the restriction homomorphism to `Q^B2`, or the quotient by functions vanishing on B2; the seven low-degree polynomial representatives need not themselves remain closed under full multiplication.

This is a concrete exact-reuse capability, with a deliberate limit. For arbitrary laws, applying an input map `H` while keeping the same retained-site receiver `S` is exact from `f|S` alone exactly when `H(S)` is contained in `S`. If the inclusion fails, two laws can agree on every retained site and disagree at the newly reached site. Iteratively adding map images yields the least forward-closed repair **among retained-site supersets for arbitrary laws**. This is not minimality among every encoding, constrained law class or storage budget. When both the coordinates and the question move coherently, the corresponding old observations can remain sufficient without recovering the omitted value.

The public composition example is `p=(h*x)*y=hxy`. Its C2 summary is zero, yet its omitted value is one. The sum `p+p=2hxy` also has zero C2 but omitted value two. Boolean products stay Boolean; Q-sums conservatively lift to `rational_cube`, including this invisible escape from the Boolean family. A false Boolean claim is rejected when the eight-site input is promoted. With valid backing, composition recipes recover the **composed result**, not an operand or a zero-filled guess. Hot arithmetic, retained storage, recipe construction/replay and backing reads are separate costs; no runtime advantage is claimed.

`ONE/EXACT` for these operations names the unique retained output. It does not identify a unique complete law. The reached Boolean C2 fiber has exactly two full Boolean laws, differing at the omitted site. General rational fibers and Q-sum candidate-family propagation are not returned by this API. Its legacy raw `MANY/REOPEN_REQUIRED` flag means the requested operation needs unavailable information; do not relabel it as a returned, complete solved Q-family. A missing expected file yields `OPEN/UNRESOLVED`; an invalid promised backing route yields `NONE/INVALID_DEPENDENCY`, referring to accepted backing artifacts, not to an empty mathematical family.

Named maps and generic certified maps share the admission gate. An arbitrary site map can turn `h` into `hx`, so the raw reference helper clears the degree guarantee and certified continuation contract. Affine hot-flip reuse is mathematically possible, but the public map API does not use `degree_bound` to perform an unbacked flip. Coherent transport can fall back to sufficient hot observations after failed access, although it attempts backing first and may do an unnecessary read when backing exists. C1 adds the existing `_validate_site_map` check before coherent receiver construction or reopening. The baseline could return `ONE/EXACT` with an empty receiver for `(-1,)*8` or `(8,)*8`; these reproduced out-of-carrier inputs are now rejected. This is an admission repair, separate from the unchanged valid-map equations. The original module remains at `history/r2_runtime/experiments/core_recovery_bridge_01_r2/prestige_envelope.py`; the repaired module retains the R2 directory for portable compatibility and has SHA-256 `e5ad46b6a8dc863b19f41a279ffeed882dad8ad6670a644fc4b3c71bebe59d68`.
