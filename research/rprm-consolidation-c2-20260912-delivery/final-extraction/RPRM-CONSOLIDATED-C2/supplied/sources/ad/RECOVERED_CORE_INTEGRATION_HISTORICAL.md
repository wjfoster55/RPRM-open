## Flagship bridge already supplied

On the three-switch cube, retain all values except the all-on vertex. Equivalently,
retain the seven multilinear coefficients of degree at most two. This summary
supports pointwise addition and multiplication of the retained functions.

The functions `f0=h+x+y` and `f1=h+x+y+h*x*y` agree at all seven retained sites.
Flipping h while holding the retained receiver fixed brings the previously omitted
value into the requested view: the output at `(0,1,1)` becomes 3 versus 4. A summary
alone cannot supply that new answer for both functions. Retaining the missing
coefficient or reopening the actual source repairs it.

By contrast, coherently transporting both the coordinate view and observation set
preserves the original seven observations without needing more information.
This positive control prevents treating every coordinate change as a failure.

For all functions on a finite site set X, restriction to S supports a fixed-receiver
pullback by H exactly when H(S) is contained in S. Closing S under the declared input
maps supplies the least sufficient retained-site superset in that family. This does
not establish minimum size over arbitrary encodings or a bound on implementation cost.

- exact readout at seven named sites;

- unresolved if that needed data is unavailable;

Do not mark every missing backing artifact as invalidating every hot operation:
its relevance depends on the specific requested use. A hash alone is not a recovery
route; repeated occurrence of the same displayed value is not proof of the same
history or permitted operation set.
