# Prestige and precision: bounded test plan

The user proposes that a higher prestige level may supply a meaningful
resolution boundary, beyond which apparent decimal detail is rounding
noise or currently unknown structure. Test this without choosing a cutoff
as an exact-equality axiom. Preserve all prior packets and other lanes.

P1. Demonstrate genuine binary64 loss near 2^53 on a finite integer set,
alongside exact Fraction arithmetic. This is a control, not a model of the
actual BSD program. Inspect the actual producer code separately.
P2. Recalculate only the attributed A/B interval widths and final
subtraction from exact rational endpoints. Compare the rounding error
introduced by doing that last subtraction in binary64. No new L-function
or height evaluation and no saved PASS substituted for source inspection.
P3. Reuse the actual prestige-envelope example of Boolean cube laws:
retain seven of eight values; enumerate all 256 laws and complete summary
fibers. Test whether the summary decides global equality to zero. Retain
the omitted bit and its reopening route as data, not noise.
P4. Determine by exact endpoint arithmetic the nearest-decimal rounding
readout of Q=A/B1, for 0 through 6 decimal places. Tie convention: half up
on these positive inputs. Contrast a certified coarse rounded result with
exact equality. No integrality or rational-denominator bound is assumed.
P5. Test retained changes of scale on the finite set of scales 1,10,10000
and exact discrepancy 1/10000. An invertible normalization changes size
but preserves whether the discrepancy is zero.

Evidence grades: existing source concepts are attributed; current models
are declared; finite tests and written preservation/counterexample proofs
do not establish a new BSD identity. Full prestige semantics remain broader
than the particular envelope implementation.
