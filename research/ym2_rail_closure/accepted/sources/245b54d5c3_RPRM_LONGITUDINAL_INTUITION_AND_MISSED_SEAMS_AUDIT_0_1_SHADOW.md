## 6. New exact arithmetic seam: the trash is a signed section defect

For base `b>=2`, every integer has the unique Euclidean normalization

```text
z = r + b*q,       0 <= r < b.
```

`r` is the visible local normal form. `q` is the signed next-scale state:

```text
q > 0   carry
q = 0   no routed residual
q < 0   borrow / signed debt
```

The weighted local accounting law at place `i` is

```text
b^i*z = b^i*r + b^(i+1)*q.
```

The quotient is not destroyed. On settlement it becomes the next place's
ordinary input. Repeating the same normalizer is the “old river does it
automatically” mechanism.

The more structural form uses a chosen residue section
`s:Z/bZ -> Z`:

```text
s(a)+s(c) = s(a+c mod b) + b*C_s(a,c),

C_s(a,c) = [s(a)+s(c)-s(a+c mod b)]/b.
```

`C_s` is a signed section-defect cocycle. Its cocycle identity is precisely
the associativity/route-consistency check. It is the exact missing correction
between local modular addition and the lifted integer result.

This formula is assistant mathematical translation. William's early source
anticipated the missing lift, return lane, and negative half; it did not state
the cocycle.

### 6.1 Why the ordinary negative side never self-clears

With ordinary digits `{0,...,b-1}`:

```text
-1 = (b-1) + b*(-1).
```

Repeated unsigned normalization leaves terminal quotient `-1`. A finite
artifact must retain a signed top quotient/sign-extension receipt; dropping it
is loss. Infinite leading `(b-1)` digits are the other representation of the
same unresolved sign.

### 6.2 The exact balanced-ternary hit

Base three is the smallest radix with a symmetric, nonredundant integer digit
alphabet:

```text
D = {-1,0,+1}.
```

Balanced normalization is

```text
q = floor((z+1)/3),
r = z-3*q,
r in D.
```

Every finite signed integer reaches terminal quotient `0`. More strongly, the
local full-adder is type-closed:

```text
N_3 : D x D x D -> D x D
      left, right, incoming residual
          -> visible trit, outgoing residual

a+b+c = r+3*q.
```

All 27 local input assignments produce both `r` and `q` in the same alphabet
`D`; the carry histogram is `q=-1:4`, `q=0:19`, `q=+1:4`.

At the boundary:

```text
+1 + +1 = -1 + 3*(+1)
-1 + -1 = +1 + 3*(-1).
```

Three therefore does not eliminate residual production. It makes the signed
residual ordinary next-rung material without an adapter. This is the exact
arithmetic version of “sort the trash lane, then use it as feed.”

The binary half-offset remains a distinct view: `{0,1}` centers to
`{-1/2,+1/2}` or scaled signs, but two integer symbols cannot simultaneously
provide negative, zero, and positive as a symmetric nonredundant residue
alphabet.

## 9. Distributed rhythm: acquire, phase-lock, and track sparsely

William first reproduced the composite rhythm by distributing sparse events
across foot, mouth, hand, and occasional voice while retaining the song
internally as the reference pulse. He then found a stronger compression: after
the dense pattern was established, four or five snaps per refrain could keep
the whole pattern available, and several different snap patterns worked. If he
tried to track the gestures or volume explicitly, the sparse performance
degraded; returning briefly to the denser version restored it.

That is not one fixed compressed copy of the song. It is a known-template
tracking system:

```text
dense ACQUIRE
-> internal template and phase lock
-> sparse TRACK landmarks
-> predicted template fills the intervals
-> loss of lock triggers dense REACQUIRE.
```

Let a frozen cyclic template be

```text
T : Z/NZ -> A
```

and let `M` be a set of sampled offsets. For candidate phase `theta`, define

```text
Sig_M(theta) = (T(theta + m)) for m in M.
```

For exact phase recovery, `M` is sufficient when `Sig_M` is injective on the
declared phase states. For a coarser receiver, equality of signatures need only
match that receiver's phase-equivalence classes. There may be many incomparable
sufficient masks, so a four-snap mask and a five-snap mask can both preserve
lock without being the same code or sampling the same beat positions.

The crucial side information is the internally retained template `T`. The
snaps need not serialize the whole song; they act like sparse synchronization
or pilot events that select and verify a phase of a model already present. If
`T` is removed, the same sparse events can be compatible with many full
patterns. If phase uncertainty grows after a missed landmark, the lawful state
is a candidate phase fiber, not a guessed phase; dense reacquisition shrinks
that fiber back to one declared state.

The earlier multi-limb observation is a compatible second arm. Freeze one
shared phase and lane masks:

```text
theta in Z/NZ,
L_foot(theta), L_mouth(theta), L_hand(theta), L_voice(theta).
```

A named receiver reconstructs the admitted composite from the synchronized
lane tuple. Several local streams can therefore be represented as one common
phase plus sparse lane-specific event masks. If one lane disappears, its events
must be irrelevant to that receiver or explicitly reassigned.

The terminology must stay conditional. Call the result **hocketed** only when
the physical lane event sets are a disjoint partition whose union reconstructs
the target line. Call it a **polyrhythm** only when at least two lane words have
independently specified primitive periods or subdivisions whose least-common
multiple supplies the reunion period. The present observation already earns a
shared internal phase with sparse indexed outputs; it does not need either
narrower label.

Volume is a separate coordinate. A mask that distinguishes phase in a symbolic
rhythm need not distinguish `(phase, amplitude envelope)`. Trying to follow
volume therefore changes the receiver and can invalidate an otherwise adequate
phase mask without changing the underlying phase result.

A smallest executable calibration should use authored finite cyclic templates,
enumerate every sample mask, compute all minimal sufficient masks, and run a
state estimator with `ACQUIRE`, `TRACK`, `AMBIGUOUS`, and `REACQUIRE` states.
Controls should include a second template agreeing on the sparse landmarks,
phase drift, wrong period, dropped or collided landmarks, lawful lane
reassignment with an effective-phase epoch, amplitude-only differences, silent
rest versus dropout, multiplicity hidden by Boolean union, and genuine template
ablation. A compact `N=12` packet can include separate shared-clock,
hocket-partition, and `3:4` polyrhythm arms without treating those three as the
same construction.

The nearest existing vocabulary is the RPRM Lexicon's Shadow
`Cross-cadence`, `common pulse`, `phase`, and `synchronization joint`. The new
piece is the explicit dense-acquisition/sparse-tracking receiver comparison.
