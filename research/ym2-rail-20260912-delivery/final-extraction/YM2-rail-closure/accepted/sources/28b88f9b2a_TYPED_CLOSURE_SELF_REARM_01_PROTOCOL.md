## Question

> Can each admitted atomic successor be represented as an archive-independent
> five-role closure state that is already a lawful next input, and do
> six-symbol predictive classes shared across distinct frames remain
> behaviorally equal at sealed horizons seven and eight?

The two clauses deliberately separate software construction from a
discriminating data question. Exact typed validation is guaranteed by the
chosen representation. Cross-frame behavioral equality is not.

## Five semantic roles

The provisional state is

```text
C5 = <amount, orientation, anticipation, frame, readiness>
```

| Role | Exact software meaning |
| --- | --- |
| Amount | Atomically committed material transfer amount |
| Orientation | Current address, target interface, and next directed step under one sealed agitation probe |
| Anticipation | Frozen complete-length-six predictive class and its recorded horizon status |
| Frame | Interface addresses, register roles, coupling mode, and a candidate-ID-free selected-law-context hash |
| Readiness | Conjunction of ledger, remainder, amount binding, interface, orientation, predictive-sufficiency, and lawful-successor facts |

Five is not rewarded merely for being five. A coordinate mismatch is rejected
as a construction control, but the result must not call that a discovered
five-part law.

## Behavioral equality and the possible redundancy

If anticipation class `kappa` truly denotes complete lawful future behavior,
then every future-relevant difference in amount, orientation, or frame is
already compressed into it. Those fields may still be useful typed validation
or interpretation, but they are not additional predictive coordinates.

The frozen source supplies a real discriminator. Some complete-length-six
class IDs occur in more than one subject and amount. For every such shared
class, this analysis compares the already sealed complete length-seven and
length-eight response signatures across distinct law frames:

- one signature at both horizons supports `kappa` sufficiency over the
  observed frames;
- a split at either horizon is a finite-horizon cross-frame alias; and
- amount plus orientation plus frame is reported as a sufficient refinement
  only when each observed contextual subgroup is homogeneous.

No class is refit or repaired after a split.

## Active/archive separation

The active closure projection contains no chronal history, provenance label,
or inverse checkpoint. The archive retains:

- chronal and transaction identities;
- pre/post state hashes; and
- a complete pre-handoff checkpoint.

That checkpoint must restore the exact prestate, while archive relabeling must
leave the active projection unchanged. Exact restore is expected because full
context is retained externally. It does not make the dissipative native active
law reversible.
