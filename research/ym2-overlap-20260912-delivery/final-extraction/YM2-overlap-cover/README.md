# YM2: shared-variable overlap and the physical gap

Start with [RESULT.md](RESULT.md) and its [visual](overlap_cover.png).
This is the next bounded research continuation, not a paper or closeout.

- [BLOCK_COVER.md](BLOCK_COVER.md): actual-vacuum forest-complement theorem,
  exact energy counts, direction factor, finite optimum and method ceiling.
- [GEOMETRIC_OVERLAP.md](GEOMETRIC_OVERLAP.md): compatible chart lift,
  reconstruction, IMS cost, physical-fold distinction and second audit.
- [OVERLAP_INVERSE.md](OVERLAP_INVERSE.md): exact failures, free repairs,
  and the interacting inverse estimates still needed.

- [RESULTS.json](RESULTS.json): new exact finite controls.
- [SOURCE_PROVENANCE.json](SOURCE_PROVENANCE.json): accepted-source hashes.

From this directory, the portable read-only check is:

```text
python -I -B -X utf8 check_overlap.py
```

It needs only the Python standard library. The optional figure generator
[draw_overlap.py](draw_overlap.py) uses already available NumPy and
Matplotlib; the delivered PNG and SVG require no regeneration or
installation. This is an explanatory plot of formulas, not a simulation.

Accepted YM1/YM2 work and the prior construction are starting evidence;
their verifiers were not rerun. New files are confined to this research
continuation and its export directory. No publication, installation,
paid compute, git mutation, or other-lane edit is part of this task.
