# Optional physical-mechanism scout: capillary transitions and Haines jumps

**Status: source-grounded proposal, not a run.** Do not let this scout replace the planned transport project or consume the third-domain held-out task.

## Why inspect it

The primary studies in SOURCES.md connect abrupt pore-scale displacement with geometry, coupling to surrounding apparatus, and observational limitations. This is a physically grounded place to investigate the user's buildup/transition/continuation intuition without putting numbered stages into a simulation by definition.

## Bounded deliverable

Read the 2026 system-softness paper and the 2023/2024 stroboscopic study. Extract their actual state variables, assumptions, measured quantities, independent controls, event definitions, and available source data. Separate repeatable-cycle reconstruction from observations of one continuously recorded realization.

Start with the smallest published single-constriction or pores-in-series model that can be reproduced, not a large tomography download. Before coding, establish which terms supply actual time evolution, compliance, and interface motion. A thresholded network invasion sequence is not a physical millisecond clock.

OpenPNM's drainage/invasion examples are useful for pressure/connectivity/sequence benchmarks. They must not be used to claim timed Haines dynamics unless an appropriate independently justified dynamic model is added.

Candidate question, not an established RPRM result: which small state description predicts whether the next interface event pauses, crosses one throat, or spans several, and which part of that description belongs to the surrounding apparatus rather than the pore alone?

Compare with the published physics-based predictor first. A jump produced by inserting a threshold does not establish an independently discovered carry law. In any later measurement-perturbation comparison, distinguish a recorder hidden from an observer from removing/changing the physical sensor.

Output one readable mechanism card and an admission verdict: what can be reproduced from available sources, what needs additional data, and which RPRM process mapping remains speculative. No clinical, remediation, or field-deployment claim.
