# Assessment F: relational-layer and application transfer

Use only the supplied version-6 handbook, these questions and ordinary
mathematical reasoning. Answer all six questions, showing the relevant
reasoning. Name missing assumptions instead of importing companion files.

1. A reader says: “The name RPRM tells me that pressure has now been proved
   to cause gravity, and your closure theorem proves the relational layer
   exists.” Give the full name, its origin and a precise explanation of
   which claims the handbook actually supports.

2. A source has states `(v,h)` in `{0,1}^2`, observation v, and action
   `tick(v,h)=(1-v,1-h)`. Compare `(0,0)` and `(0,1)` under all finite tick
   sequences. Now add `probe(v,h)=(v XOR h,h)`. Can the same summary v
   support both actions? Does the original visible behavior establish that
   h physically exists or that no possible experiment can observe it?

3. A target has one state q and permits `Phi_t(q)=q` for every t>=0. A source
   state `(q,h)`, h>0, permits `Psi_t(q,h)=(q,h-t)` only for `0<=t<h`.
   Let C(q,h)=q. A proposed proof checks the commuting equation whenever
   both sides are defined and concludes an exact operational bridge with
   identical futures. Audit that conclusion, giving a concrete separating
   case and the missing condition.

4. Admit real coordinates x,y,z and exact observed relations `y-x=4` and
   `z-y=-1`. Give the complete source fiber, the possible values of `z-x`
   and of x, and explain whether the source or a property has been
   identified. What further premise would be needed to turn this into a
   claim about an actual physical source?

5. Two proposed studies report success. A folding reduction matches
   stationary block occupancies but two states in one block have next-block
   probabilities `(3/4,1/4)` and `(1,0)`. A cellular-score representation
   gives every training record its own identifier and hence zero fiber
   error; its proposed comparison gives only the candidate a measured RNA
   input. Evaluate these claims, name fair comparisons and explain the
   currently reported status of the repository's two main science proposals.

6. For the fixed-gap problem take `n=2,s=2,d=2`. Derive D(a), use the
   handbook's bound and sign/monotonicity contract to give the complete
   positive-integer fiber and reconstructed triple. Would successful
   execution for many n>2 gap pairs prove their universal emptiness? What
   result is lawful if execution is interrupted before completion?

Finally state whether any concept required by these questions was missing
or ambiguous in the supplied handbook. Declare the actual inputs and tools
