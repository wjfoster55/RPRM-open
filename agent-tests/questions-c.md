# Handbook-only assessment C

Read only the supplied current handbook and these questions. Use ordinary
mathematical reasoning, but no other source, previous task or web lookup.
Answer every question, identify the exact assumptions and note any handbook gap.

1. On Z/6Z the relation is x+y=z. Supply z=2 and request the joint pair (x,y).
   Give the complete fiber. Repeat on {0,1,2} using ordinary addition without
   wrap. Explain why these are different contracts and what happens if the
   second answer is replaced by the product of its two marginals.
2. On integers the relation is y=x^2. Given y=-1, y=4 and y=0, solve for x
   completely. Is the converse of this total forward function itself a total
   single-valued inverse? Explain the role of the carrier.
3. Paths x->m->z and x->n->z have m!=n and share endpoints. An endpoint
   representation retains only (x,z). State exactly what it preserves and
   what reconstructing the middle point requires. Does unique endpoint data
   establish a unique path?
4. On X={0,1,2,3,4,5}, let C(x)=x mod 2 and Q(x)=1 if x=0, else 0.
   Does Q descend? Construct the least question refinement retaining C and Q,
   find the minimum reusable repair-tag alphabet size, and state the empty-X
   convention. Explain why that information bound is not a running-time bound.
5. A deterministic machine has states s,t,u, observations 0,0,1, one action a,
   and transitions s->s, t->u, u->u. Find the future-equivalence classes and a
   shortest distinguishing word for s,t and for t,u. Is present observation
   alone a lawful operational quotient?
6. A system has two states but infinitely many named actions, provided by an
   enumerator that never announces completion. Someone proposes running the
   handbook's finite-table refinement algorithm to completion. Are its
   termination premises met? Would two finite tables with an undecidable
   observation equality meet the premises? State the actual finite contract.
7. State p has no a-transition and q has an a-transition to r, whose observation
   is the ordinary value NONE. p and q currently look equal. May failed a at p
   be equated with successful a at q because its returned value is named NONE?
   Explain enabledness, tagging and the consequence for the quotient.
8. Two probability transitions reach the same two observable classes but put
   masses (1/4,3/4) and (3/4,1/4) into them. State the set-valued and stochastic
   preservation conclusions, assuming current observations agree. Does equal
   support identify the probability law?
9. A source has one element with P true. Its injective target representation
   adds one unreached element where P is false. Compare the source statement
   forall x P(x), unguarded target translation and image-guarded translation.
   Does this faithful-presentation theorem decide arbitrary first-order truth?
10. Four bits have even parity. For (0,1,?,0), recover the labeled erasure.
    For received word (0,1,1,1), under exactly one bit error, enumerate all
    possible originals. Separately, do three agreeing reports establish truth
    without a bound on how many can be wrong? Give the needed distinction.
11. A constructor specifies 1 followed by 10^12 zeros in base ten. Describe its
    integer value, length and last digit without expanding it. Explain the
    indexing/cost assumptions and whether the zero count is geometric dimension.
    A compact expression 2^p-1 with prime p is called a certified prime: test
    that conclusion using p=11.
12. A checker agrees with a second checker on every case in a finite supplied
    model, then the author says this proves the checkers' own soundness and a
    biological application. Give the strongest supported conclusion, identify
    the circularity risk and missing bridge, and name what an honest OPEN
    record should retain before later continuation.
